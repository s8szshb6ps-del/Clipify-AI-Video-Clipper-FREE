# GTA-6-Skills

Dieses Repo enthält die elf Claude-Code-Skills aus
[neubauerwilli/gta6-skill](https://github.com/neubauerwilli/gta6-skill) (MIT, siehe
`.claude/skills/LICENSE-gta6-skill`) unter `.claude/skills/`.

Öffne Claude Code in diesem Ordner, dann stehen sie direkt als `/kampagnen-finder`, `/stream-finder`,
`/momente-finder`, `/clip-schneider`, `/untertitel`, `/hook-schreiber`, `/caption-und-hashtags`,
`/regel-check`, `/trend-radar`, `/kanal-bauer` und `/auszahlungs-tracker` bereit.

Voraussetzungen für Schnitt und Momente: `yt-dlp` und `ffmpeg` im PATH, optional Whisper.
Alle Arbeitsdateien landen in `gta6/`.
